A modern and responsive **Scientific Calculator** built using **HTML, CSS, and JavaScript** as part of the **CodSoft Web Development Internship**.

🔗 **Live Calculator:**

## 📌 About the Project

This project is a web-based scientific calculator that performs basic arithmetic as well as scientific calculations.

The calculator has a clean and user-friendly interface and supports both mouse and keyboard input.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📊 Percentage calculation
* √ Square root
* x² Square
* sin — Sine
* cos — Cosine
* tan — Tangent
* log — Logarithm
* π — Pi
* 🔄 AC — Clear display
* ⌫ DEL — Delete last character
* ⌨️ Keyboard support
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Calculator logic and functionality
